#Z - SELF RUBIKA

A Python-based Rubika selfbot using "pyrubi".

Installation on Termux

⚡️1. Update packages

- `pkg update -y && pkg upgrade -y`
- `pkg install python git -y`
- `git clone https://github.com/Ahora-ir/Z-SELF-RUBIKA.git`
- `cd Z-SELF-RUBIKA`
- `python -m pip install --upgrade pip`
- `pip install pyrubi`
- `python Z_SELF_RUBIKA.py`

Features

- Timer with 5 clock font styles
- Fixed time display after 5 minutes of inactivity
- Automatic replies to private messages
- Group member information lookup
- Optional message formatting
- AI-style keyword responses
- Command-based feature controls

Requirements

- Android with Termux
- Python 3
- Git
- pyrubi
